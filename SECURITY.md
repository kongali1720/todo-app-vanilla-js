# Security Policy

Thank you for helping improve the security of **todo-app-vanilla-js**.

We take security seriously and appreciate responsible disclosure of vulnerabilities.

---

# Supported Versions

The following versions are currently supported with security updates.

| Version | Supported |
|----------|:---------:|
| Latest Release | ✅ |
| Development Branch | ✅ |
| Older Versions | ❌ |

---

# Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub Issue**.

Instead, report it privately to the project maintainer with as much detail as possible.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Expected behavior
- Actual behavior
- Affected version
- Browser and operating system
- Screenshots or proof of concept (if applicable)
- Suggested mitigation (optional)

---

# Response Timeline

We aim to respond according to the following timeline:

| Stage | Target Time |
|--------|-------------|
| Initial Response | Within 48 hours |
| Vulnerability Assessment | Within 7 days |
| Status Update | As needed |
| Security Fix | As soon as reasonably possible |

Please note that complex issues may require additional investigation.

---

# Scope

This policy applies to:

- HTML
- CSS
- JavaScript (Vanilla JS)
- Documentation
- GitHub Actions
- Repository configuration

---

# Out of Scope

The following are generally considered out of scope:

- Browser-specific issues
- Third-party library vulnerabilities
- Social engineering attacks
- Denial-of-Service (DoS) attacks
- Physical attacks
- Vulnerabilities requiring physical access
- Issues caused by outdated browsers

---

# Responsible Disclosure

Please:

- Allow reasonable time for investigation.
- Avoid public disclosure until a fix is available.
- Do not exploit vulnerabilities beyond what is necessary to demonstrate the issue.
- Do not access, modify, or destroy user data.

Responsible disclosure helps protect all users of this project.

---

# Security Best Practices

When contributing to this project:

- Validate all user input.
- Keep JavaScript code clean and maintainable.
- Avoid introducing unnecessary dependencies.
- Follow secure coding practices.
- Review Pull Requests carefully before merging.

---

# Security Updates

Security-related fixes will be documented in:

- CHANGELOG.md
- GitHub Releases

---

# Contact

For private security reports, please contact the project maintainer through GitHub.

If GitHub Security Advisories are enabled for this repository, please use the private reporting feature.

---

Thank you for helping keep **todo-app-vanilla-js** secure for everyone.
