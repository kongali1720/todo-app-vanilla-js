# Contributing to todo-app-vanilla-js

First off, thank you for taking the time to contribute! 🎉

Your contributions help improve this project and make it more useful for everyone.

---

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Fixing issues
- Improving the UI/UX
- Optimizing JavaScript code
- Refactoring existing code
- Adding tests
- Improving accessibility
- Helping review Pull Requests

---

## Getting Started

1. Fork this repository.
2. Clone your fork.

```bash
git clone https://github.com/YOUR_USERNAME/todo-app-vanilla-js.git
```

3. Navigate into the project.

```bash
cd todo-app-vanilla-js
```

4. Create a new branch.

```bash
git checkout -b feature/your-feature-name
```

---

## Coding Guidelines

Please follow these guidelines:

- Write clean and readable code.
- Keep commits focused on a single change.
- Use meaningful commit messages.
- Maintain consistent formatting.
- Test your changes before submitting.

---

## Commit Message Examples

```text
feat: add dark mode

fix: resolve delete button bug

docs: update README

style: improve layout

refactor: simplify DOM manipulation
```

---

## Pull Requests

Before opening a Pull Request:

- Sync your branch with the latest `main`.
- Resolve merge conflicts.
- Verify the application works correctly.
- Update documentation if necessary.

---

## Reporting Bugs

Please include:

- Browser name and version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

## Feature Requests

Feature requests are welcome.

Please describe:

- The problem
- Your proposed solution
- Any alternatives considered

---

## Code of Conduct

By participating in this project, you agree to follow our Code of Conduct.

## Questions

If you have any questions, feel free to open an Issue.
