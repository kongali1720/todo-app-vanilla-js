# Support

Thank you for using **todo-app-vanilla-js**.

This document explains how to get help, report issues, and contribute to improving the project.

---

# Getting Help

If you have questions or encounter problems, please check the following resources before opening a new issue:

- README.md
- CHANGELOG.md
- ROADMAP.md
- Existing GitHub Issues

Many common questions may already have an answer.

---

# Reporting Bugs

If you discover a bug, please open a GitHub Issue and include the following information:

- Project version
- Browser name and version
- Operating system
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Error messages (if any)
- Screenshots (if applicable)

Providing detailed information helps resolve issues more quickly.

---

# Requesting Features

Feature requests are always welcome.

Please include:

- A clear description of the feature
- The problem it solves
- Possible implementation ideas
- Any alternatives you have considered

---

# Security Issues

If you believe you have found a security vulnerability, **please do not report it publicly**.

Instead, follow the instructions in:

- SECURITY.md

Responsible disclosure helps protect all users of this project.

---

# Before Opening an Issue

Please verify that you have:

- Read the README.
- Checked existing Issues.
- Updated to the latest version.
- Tested the issue in a supported browser.
- Included enough information for reproduction.

---

# Browser Support

This project is designed to work with modern browsers, including:

- Google Chrome

- Safari

Older browsers may not be fully supported.

# Frequently Asked Questions

### Is this project beginner-friendly?

Yes. This project is intentionally built using Vanilla JavaScript so that beginners can easily understand the code.

---

### Does this project require Node.js?

No.

You can simply open `index.html` in your browser.

Node.js is only recommended if you plan to extend or automate the project.

---

### Can I use this project commercially?

Yes.

Please review the terms in the LICENSE file.

---

### Can I modify the source code?

Absolutely.

Fork the repository, make your changes, and submit a Pull Request if you'd like to contribute them back.
