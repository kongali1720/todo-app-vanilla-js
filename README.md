## 🚀 Cara Menjalankan

Clone repository:

```bash
git clone https://github.com/kongali1720/todo-app-vanilla-js.git
```

Masuk ke folder project:

```bash
cd todo-app-vanilla-js
```

Kemudian buka file:

```
index.html
```

menggunakan browser favorit Anda.

---

## 📖 Cara Menggunakan

1. Ketik tugas pada kolom input.
2. Klik tombol **Tambah**.
3. Klik tugas untuk menandainya selesai.
4. Klik tombol **Hapus** untuk menghapus tugas.
