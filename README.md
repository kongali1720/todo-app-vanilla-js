<h2>🚀 Cara Menjalankan</h2>

Clone repository:

```bash
git clone https://github.com/kongali1720/todo-app-vanilla-js.git
```

Masuk ke folder project:

```bash
cd todo-app-vanilla-js
```

Buka file menggunakan browser:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Atau jalankan menggunakan local server:

```bash
npx serve .

# atau

python3 -m http.server 3000
```

<hr />

<h2>📖 Cara Menggunakan</h2>

1. ✍️ Ketik tugas pada kolom input.
2. ➕ Klik tombol **Tambah** atau tekan **Enter**.
3. ✅ Klik tugas untuk menandainya selesai.
4. 🗑️ Klik ikon **Trash** untuk menghapus satu tugas.
5. 🧹 Klik tombol **Clear** untuk menghapus seluruh daftar tugas.
